# 口述史磁带 WAV 削波核验台

纯浏览器运行的 WAV 削波（短促 clip）核验工具。质检员选择**本地单个 WAV 文件**后，
页面在本机用 Web Audio API 解码、按声道扫描归一化 PCM、Canvas 2D 绘制波形并高亮削波段。
**文件不上传、不访问任何在线服务**（无后端、无外部请求），刷新页面即释放。

## 判定规则

- 削波帧：归一化 PCM 样本 `|x| ≥ 0.999`；
- 连续至少 **3 帧**才形成削波段；
- 相邻段间隔 **≤ 2 帧必须合并**，间隔 **≥ 3 帧不得合并**（间隔 = 下段首帧 − 上段末帧 − 1）；
- 段起始时间 = 首帧 / 采样率；结束时间 =（末帧 + 1）/ 采样率；
- 毫秒显示取最接近整数，恰为 0.5 时向上取整（half-up）；
- 总削波时长 = 各声道区间时长**累加**；同一时刻多声道削波**分别计入**；
- 任一声道存在削波段 → 结论 **“需重采”**；全部声道无区间 → **“可交付”**。

## 候选规则比较

调整质检规则前，可输入候选规则试算差异，**不覆盖按现行标准生成的基线结论**：

- 可输入 `threshold`（0 < 值 ≤ 1）、`min_run_frames`（正整数）、
  `max_merge_gap`（非负整数）；
- 非法输入就地提示并**保留上一次有效比较**；新文件载入或解码失败自动清空旧比较；
- 候选扫描复用已解码 PCM，不重复读取或解码文件；
- 逐声道以原始帧坐标把两套合并后区间切成最大连续差异片段，标记
  **BASELINE_ONLY**（新规则漏掉）/ **CANDIDATE_ONLY**（新规则新增）/ **BOTH**；
  只有成员集合相同且帧相邻的片段才合并，毫秒仅用于展示、不参与边界裁决；
- 页面并列显示两套结论与段数，差异表可定位试听，波形底部差异条按同一差异数组着色；
- 基线摘要、原红色削波层与未启用比较时的交互保持不变。

## 返工文件对照

质检员收到**同一段录音的返工文件**后，在不改动上述单文件基线结论的前提下，
再载入一份返工 WAV，先对齐再裁决，避免把两份文件**录制起点相差几十帧**
造成的整体错位误判成“削波被修复”或“新引入削波”：

- 质检员在原件上选取一段**有效声音**作锚点（起点、长度、限定帧偏移范围、声道），
  对两份**已解码 PCM** 做去均值归一化互相关（NCC，与整体幅度无关，增益变化不影响对齐）；
- 偏移定义为 `返工帧 = 原件帧 + d`，在 `[-maxOffset, +maxOffset]` 且窗口完整落在
  返工 PCM 内的候选里，按固定顺序确定**唯一**结果：
  **最高相关度 → 最小绝对偏移 → 偏移符号（平局负偏移优先）**；
- **静音或能量不足的锚点不得强行对齐**：锚点 RMS 低于阈值、候选窗口静音/零方差
  （或范围内没有任何可归一化窗口）时直接报 `ANCHOR_LOW_ENERGY`，不产出对照；
- 两份扫描只在**真实重叠的原始帧范围**内逐帧裁决，边界只使用帧坐标、毫秒仅用于展示：
  - **仅原件（返工已修复）** / **仅返工件（新引入）** / **两边仍削波（未修复）**；
  - 任一份扫描**未覆盖**的帧标记为**不可比较**（原件/返工各一种标记），
    绝不算作任何一侧独有的质量差异，片段的另一套坐标留空显示为 “—”；
- 差异表、双波形着色条与定位试听**共用同一个偏移和同一片段数组**：
  双波形分别按各自文件坐标对着色，点击片段时两个播放器分别映射到该片段在
  原件 / 返工件上的时间点试听（只一侧存在的片段只定位存在侧）；
- 状态隔离：
  - 返工文件**解码失败时保留已确认的旧对照**（连同旧返工播放器），仅就地报错；
  - **新基线载入**（成功或失败）立即清空返工对照；
  - 基线与返工的异步解码、相关计算均带单调令牌，**迟到结果不能覆盖较新的文件**；
  - 采样率或声道数不一致不做对照并就地提示。

错误均显示明确原因且**不生成任何结果**：

| 错误码 | 含义 |
| --- | --- |
| `NOT_WAV` | 文件不是有效的 WAV（缺 RIFF/WAVE 标识等） |
| `CORRUPT` | WAV 损坏或被截断（RIFF/区块尺寸不一致、fmt 字段非法等） |
| `NO_TRACK` | 不含可读取音轨（无 data 区块、0 帧、解码后无声道） |
| `DECODE_FAILED` | 浏览器解码失败或扫描异常 |

RIFF 区域完整性在解码前稳定裁决，判定不随浏览器变化：

- 区块只允许出现在 RIFF 声明区域内；**文件尾附带的任何区域外字节**
  （包括可解析的 fmt/data 块）一律判 `CORRUPT`，不会当成有效内容；
- 区块体（含奇数尺寸块的对齐填充）越过 RIFF 区域末端即判 `CORRUPT`，
  即使它仍在物理文件内也不进入解码；
- `data` 长度必须是完整采样帧的整数倍，尾部不足一帧判 `CORRUPT`，
  绝不向下取整成较短帧数再出扫描结果；
- 区域内的合法扩展块（LIST/fact 等，含奇数尺寸 + 对齐填充）正常放行。

## 局部视窗

点击**“定位首个异常”**或任一削波区间后，播放器仍跳到该段起点，同时所有声道
同步切换到该时刻附近的**局部波形**，便于对照上下文：

- 波形上方可填写**局部视窗秒数**（默认 10 秒）并点击**应用**；
- 录音时长 **>** 所填秒数：视窗保持该宽度，以关注时刻为中心，触及首尾只平移范围；
- 录音时长 **≤** 所填秒数：回退整轨并提示“录音短于局部视窗，已显示整轨”；
- 整轨/局部起止秒数收敛为一组页面视图状态，由纯函数（`src/audio/view-range.ts`）
  计算，Waveform 据此换算包络、高亮、游标与点击定位；
- **返回整轨**随时可回到完整波形；
- 输入为空、非数字或不大于零：不改变当前视图，就地提示“局部视窗秒数必须大于零”，
  已生成的核验结果仍可操作。

## 测试

```bash
npm test                       # Vitest 单元测试（含 95% 覆盖率阈值）
npx playwright install chromium
npx playwright test            # Playwright 端到端（自动 build + preview）
```
- Vitest 覆盖：阈值边界（含 0.999 恰为阈值、−0.999）、连续帧（1/2/3 帧）、
  合并边界（间隔 1/2/3 帧）、换算边界（0.5 向上、8000Hz/44100Hz 取整）、
  WAV 头损坏分类、解码失败/无音轨链路，
  RIFF 区域完整性（区域外格式块/普通尾随字节、越界音频块、
  区块对齐填充越界、区域内残留字节、半帧尾部、合法扩展块），
  局部视窗的居中、首尾平移、等长回退与非法输入解析，
  候选规则比较的逐帧标记预言机校验（阈值相等、最短游程、合并间隙、
  嵌套、相交、相邻区间与多声道），
  以及返工文件对照：锚点 NCC 的合成移位 PCM（正/负偏移、边界偏移、
  幅度归一化、窗口越界）、裁决三层顺序（相关度→|偏移|→符号）、
  静音/低能量/零方差锚点拒绝、参数解析，
  重叠区逐帧裁决（修复/新引入/未修复、正负偏移、长度不等、
  无重叠、覆盖空隙不合并、多声道合计）与采样率/声道守卫。
- Playwright 覆盖：本地 WAV 载入、双声道仅实际削波声道高亮、
  点击“定位首个异常”与区间行定位、结论（需重采/可交付）、
  截断损坏/无音轨/非 WAV 的失败提示，
  结构完整性固定字节样本（区域外格式块、越界音频块、半帧尾部稳定判
  CORRUPT 且无扫描结果/比较入口；合法扩展块正常解码、帧数正确、可进入比较），
  局部视窗四场景（中部长录音跨声道同步、边界削波保持指定宽度、
  短录音提示整轨回退、非法输入提示后原结论与区间仍可见），
  候选规则比较（无差异、结论双向翻转、非法输入保留上一次有效比较、
  换文件/解码失败清空旧比较），
  以及返工文件对照（合成移位 PCM 唯一对齐与修复/未修复裁决、双播放器分别
  映射定位、静音锚点拒绝、多声道、解码失败保留旧对照、新基线清空、
  快速换文件的迟到结果隔离、非法输入保留旧对照、未覆盖区不可比较）。

## Docker Compose

```bash
# 启动 web（宿主端口可用 WEB_PORT 覆盖，默认 8080）
WEB_PORT=9090 docker compose up -d web
# → http://localhost:9090

# 一次性验收服务：Vitest（覆盖率阈值）+ Playwright 端到端，全部通过退出码 0
docker compose --profile verify run --rm verify
```

`verify` 服务直接对 compose 网络中的 `web` 服务跑 Playwright（`PLAYWRIGHT_BASE_URL=http://web:8080`），
结束后容器退出，不驻留服务。
